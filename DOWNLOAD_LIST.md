# Kenney source pack received

The files were found under the literal workspace folder `publicsounds-rawui-audio/`, rather than `public/sounds-raw/`. The included `License.txt` identifies the pack as **UI SFX Set by Kenney Vleugels**, released under **CC0 1.0**. Its official page is [Kenney UI Audio](https://kenney.nl/assets/ui-audio).

The OGG files and license were reviewed in place; the raw folder was not changed or included in the commit. The second suggested pack, [Interface Sounds](https://kenney.nl/assets/interface-sounds), was not present. All 14 published sounds therefore use the available UI SFX Set. Shortlists, measurements, and final selections are recorded in `SOUND_CHOICES.md`; processed file credits and level measurements are in `SOUND_CREDITS.md`.
