# Direct Execution Protocol

When the user prefixes any request with `direct/`, `/direct`, or requests "Direct mode":

1. **Immediate Execution**:
   - Bypass prolonged spec discovery, planning ceremonies, and unnecessary interactive questionnaires.
   - Jump straight to research and implementation.

2. **Decisive Implementation**:
   - Directly write, edit, or refactor files with high precision.
   - Run required commands and tools without hesitation.
   - Keep solutions focused, minimal, and effective.

3. **Production Quality Standards**:
   - Deliver clean, type-safe, idiomatic code adhering to project architecture (React, TypeScript, Tailwind CSS).
   - Maintain DRY principles and preserve existing features and comments.
   - Keep error handling robust and user experience smooth.

4. **Self-Verification**:
   - Automatically verify changes with type checking (`npm run lint`), build, or dev server checks.
   - Fix any introduced regressions immediately before presenting completion.

5. **Concise Status**:
   - Report the outcome cleanly and directly without bloated boilerplate or unsolicited lectures.
